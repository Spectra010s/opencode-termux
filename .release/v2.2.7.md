## What changed upstream (2.2.6 → 2.2.7)

- **GitHub Copilot Auto**: pick **Auto** in the model picker and Copilot's router chooses the model for each session at the Auto discount, falling back to the account's default chat model when routing fails.
- **MCP logins survive token rotation**: remote servers that rotate refresh tokens no longer sign you out when several clients refresh at once or the token endpoint fails for a moment, and a failed refresh no longer marks the server `needs_auth`.
- **`read` got smarter**: a negative `offset` reads from the end of a file (`-50` for the last 50 lines), a missing file gets close-name suggestions, and long lines no longer cut an emoji in half.
- **Shell results say how they ended**: output finishes with `Exit code: N`, signals are named, and timeouts say how long they waited and suggest a larger one. Under zsh a glob that matches nothing is passed through instead of stopping the command.
- **Cache warming follows the cache**: pings are timed from the model's `cache.ttl` by default, no longer fire while a ping rebuilds the cache, and stop during compaction or after the session is deleted.
- **Code Mode sends deltas**: when MCP servers connect, disconnect or change tools, the model gets a short list of what changed instead of the whole tool catalog.
- **Breaking**: `@opencode/ai` drops `ImageResponse.image` in favour of `response.images[0]`, and SDK `agent.list`, `integration.list`, `usage.limits`, `vcs.init`, `rpc.call` and `artifact.*` no longer wait up to 5 seconds for plugins to load.
- **Also**: Copilot costs come from what Copilot charged, MCP tool calls no longer fail on a schema mismatch, markdown agents whose description starts with a bracketed tag load again, the TUI follows the terminal's light/dark mode, session exports land in the current directory, and update/confirm dialogs have buttons you can reach with `←`/`→` and `Tab`.

Desktop-only changes in 2.2.7 (side panel tab shortcuts, mark/unread menu actions, question dock styling) do not apply to this Termux build.

## What changed in this Android build

- **The package is a bundle, not a compiled binary.** OpenCode used to ship one 244 MiB executable with Bun inside it; it now ships the same module graph as JavaScript and runs on Termux's own `bun` package. The download drops from 86.6 MB to 30.8 MB, and `bun`, `ripgrep` and `libc++` are declared dependencies instead of being baked in (Termux's `bun` is 25.6 MB if it is not already installed). The launcher lives at `$PREFIX/bin/opencode`, the bundle at `$PREFIX/lib/opencode/`.
- **Everything native is still built for bionic**: OpenTUI 0.8.1 with Zig 0.17.0, `bun-pty`'s `rust-pty` rebuilt against `portable-pty` 0.9, `@parcel/watcher`'s Android module and `@ff-labs/fff-bun`'s Termux build, all installed next to the bundle. One stripped OpenTUI asset ships instead of the wasted copies Bun emits per platform.
- **The launcher owns the install**: it exports `OPENCODE_LAUNCHER` and `OPENCODE_ROOT`, so `/update`, `opencode upgrade` and `opencode uninstall` act on the wrapper and clean up the bundle instead of touching the `bun` interpreter.
- **Bionic's pointer tags still reach the FFI untouched**: the Scudo `pointer tag … was truncated` abort that 2.2.5 hit on quit stays fixed, and the OpenTUI build still writes the full Zig 0.17 `--libc` schema and shadows bionic `limits.h`.
