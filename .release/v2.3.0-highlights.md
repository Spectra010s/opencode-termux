### Highlights

- **Subagents work in the background**: they return their session ID straight away and report back when idle, so you keep working in the parent session.
- **Quieter transcripts**: each run of tool calls and thoughts collapses into one activity row; set verbosity to `medium` or `high` to see every step again.
- **A new renderer**: OpenTUI 0.8.4, still built for bionic against Zig 0.17.
- **Shell commands survive handoffs**: output is kept when a command is interrupted, and a timed-out command can move to the background behind `shell_timeout_background`.
- **Remote local models list faster**: Ollama, LM Studio and vLLM discovery waits 15 seconds per request instead of 1.
