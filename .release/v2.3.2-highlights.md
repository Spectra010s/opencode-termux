### Highlights

- **Timed-out commands keep running**: a shell command still running when its timeout expires moves to the background instead of being killed.
- **Subagents work in the background**: they return their session ID straight away and report back when idle, so you keep working in the parent session.
- **Quieter transcripts**: each run of tool calls and thoughts collapses into one activity row; set verbosity to `medium` or `high` to see every step again.
- **GPT-6.2 caching fixed**: the system prompt is cached from the second step, so Copilot `gpt-6.2-sol` drops from about 14,000 uncached tokens per step to 3.
- **Compaction without the wait**: the summary is written in the background, so your next prompt does not pause for it.
