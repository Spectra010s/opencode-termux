# OpenCode 2.3.0 for Termux

The first release after 2.2.7. Upstream skipped 2.2.8, so this is a normal minor bump: subagents now run in the background, the transcript folds tool calls behind one row, and the TUI moves to OpenTUI 0.8.4. The package is unchanged in shape — the same bundle on Termux's own `bun`, the same `apt` and `install.sh` paths.

## What changed upstream (2.2.7 → 2.3.0)

- **Subagents run in the background**: a subagent returns its session ID immediately, keeps working, and reports to the parent whenever it goes idle. Several can run at once while you keep typing in the parent session, and a subagent that goes idle with its own background work still running says so instead of looking finished.
- **Quieter transcripts by default**: each run of tool calls and thoughts collapses into one activity row. Verbosity now defaults to `low`; set **Verbosity** to `medium` or `high` in settings, or `session.verbosity` in the TUI config, to see every step. An existing setting is kept.
- **Shell commands survive handoffs**: they keep their output when interrupted, and a command whose timeout expires can move to the background behind the `shell_timeout_background` flag.
- **Local model discovery is more patient**: Ollama, LM Studio and vLLM get 15 seconds per request instead of 1, so remote or tunnelled endpoints list their models and a slow endpoint no longer delays the rest.
- **Providers can present a client certificate** for gateways that require mutual TLS, with `settings.tls` accepting `{file:}` and `{env:}` like `apiKey`.
- **Code Mode returns simpler results**: `write` and `edit` return their confirmation as a string, `patch` returns an empty result, and `skill` returns the skill directory and content. Calling a namespace as if it were a tool now suggests up to three real tools under it.
- **MCP events** are available experimentally behind the `mcp_events` flag.
- **Also**: agents are told when a session is a fork, tool output truncation keeps the beginning of the output, tail reads no longer load the whole file, case-only renames in patches work on case-insensitive filesystems, and plugin-provided themes update live.

Desktop-only changes in 2.3.0 (Jump to message, the Recent and customizable session sidebars, Mermaid zoom, queued-prompt shortcuts) do not apply to this Termux build.

## What changed in this Android build

- **OpenTUI 0.8.4** replaces 0.8.1. It is still built here for bionic against Zig 0.17.0 with the same `--libc` schema and the `limits.h` shadow, and one stripped renderer asset still ships instead of the four Bun emits.
- **The package is unchanged**: the same bundle at `$PREFIX/lib/opencode/` with a launcher at `$PREFIX/bin/opencode`, still run by Termux's `bun` with `bun`, `libc++` and `ripgrep` as declared dependencies rather than embedded ones.
- **Publishing is now one tag run**: pushing `v2.3.0` builds, verifies, signs the APT index and releases in the same workflow run, so the published files are always the ones that run built. A broken release gets a higher `package_revision` and a tag of its own (`v2.3.0-2`) instead of a silent overwrite.
- **Bionic's pointer tags still reach the FFI untouched**: the Scudo `pointer tag … was truncated` abort stays fixed.

## Install

```sh
pkg install bun ripgrep libc++
curl -fsSL https://raw.githubusercontent.com/Spectra010s/opencode-termux/native-android/install.sh | sh
```

Or through the signed APT source, so `apt upgrade` keeps it current:

```sh
curl -fsSL https://raw.githubusercontent.com/Spectra010s/opencode-termux/native-android/setup-apt.sh | sh
apt install opencode
```
