### Highlights

- **New TUI look**: the new designs are on by default and `opencode` is the new theme; pick `opencode-classic` in **Theme** for the previous colours.
- **Automations**: the agent can run a prompt, a script or a shell command on a timer, on a cron schedule or when an MCP server sends an event, managed with `/automation`.
- **Videos**: `generate_video` renders in the background and saves the finished file into your workspace; the image tool is now `generate_image`.
- **Plugins update themselves**: a plugin pinned to `@latest`, a version range or a Git branch is checked at startup and every 24 hours, and a newer match loads without a restart.
- **GitHub Copilot reads `COPILOT_GITHUB_TOKEN`**: `GITHUB_TOKEN` is ignored, so Actions and git tooling can no longer send the wrong account.
