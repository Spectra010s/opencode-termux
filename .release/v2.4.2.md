# OpenCode 2.4.2 for Termux

## What changed upstream (2.3.2 → 2.4.2)

- **New TUI look**: the new designs ship on by default and the theme named `opencode` is the new one. The previous default is kept as `opencode-classic` (`opencode2` still aliases `opencode`), and **New designs** in the Experiments dialog turns the old layout back on.
- **Automations**: the agent can schedule a prompt, a Code Mode script or a fixed shell command to run once, on an interval, on a cron schedule or when a connected MCP server pushes an event. `/automation` manages them, a shell action asks for approval once when it is created, and `"automations": false` turns the feature off. MCP push delivery, heartbeats and reconnects ship with it. A failed run is recorded and the next one stays on schedule, and a shell command inside an automation that runs past its timeout is stopped instead of moving to the background.
- **Video generation**: with a provider that has a video model, `generate_video` renders in the background, survives a server restart and saves the finished file into the workspace. `experimental_image_generate` is now `generate_image`; permission rules are mapped automatically, but saved "always allow" approvals ask once more.
- **Images and videos moved into Code Mode**: `generate_image` and `generate_video` are no longer top-level tools, so their definitions stop adding roughly 700 tokens to every request.
- **Plugins that follow a version update themselves**: `name@latest`, a version range, a Git branch or a Git `semver:` range is checked at startup and every 24 hours, and a newer match is installed and reloaded without a restart. A range stays inside its range, and a new version that fails to load leaves the previous one running.
- **`GITHUB_TOKEN` no longer signs in GitHub Copilot**, which fixes Copilot being picked up from environment variables that git tooling and Actions set. Use `COPILOT_GITHUB_TOKEN` or OAuth.
- **MCP servers negotiate the newest protocol first**, falling back to the legacy handshake; set `protocol: "legacy"` on a server that misbehaves. Sign-in also works when the configured URL has a query string, such as the AWS MCP Server.
- **A system prompt written for GPT-6.2**: GPT-6.2 Sol and Astra, and the `gpt-latest` aliases, use it instead of the general prompt.
- **Esc takes back your last message**: with an empty composer, stopping a response before the model has written anything or called a tool removes your message and puts it back in the composer, images included, so you can edit it and send again.
- **"Always allow" for a web fetch now covers that site only**, not every URL. Approvals saved earlier stay as they were.
- **Sending to an archived session unarchives it**, including messages, commands, skills and shell commands sent through the API.
- **Plan mode's rules moved into the system prompt**, and the reminder is no longer re-added after every compaction, which could keep a session running in a loop.
- **Moving a session also moves its subagents.**
- **The prompt cache survives a compaction**, long goal sessions stop paying for an extra cache write, and compaction no longer keeps more history than `keep.tokens` allows.
- **`/models` lists config-only providers** such as Ollama without a `/connect` login, and a slow project no longer leaves the model picker empty while it loads or collapses it to free models when the session was opened from another directory.
- **Shell commands the scanner cannot analyse ask for permission** instead of failing outright, and a matching `shell` deny rule still blocks them. A command that ends without an exit code now says why.
- **`edit` and `patch` refuse to rewrite a file that is not valid UTF-8** instead of replacing every Latin-1, cp1252 or GBK byte with `�`, and patched files no longer lose a trailing blank line.
- **PDFs with bytes before the `%PDF-` header are read as PDFs.**
- **Code Mode** scripts can define getters and setters, errors carry a `stack`, built-ins match Bun (`toLocale*`, base64 options, `Buffer` slices), and `tools.opencode.session.rename` and `.move` replace the old dotted paths — direct tool names and permission actions are unchanged.
- **Fixed tools staying visible to the model** when a blanket deny was followed by narrower denies, and **fixed OpenAI custom tool calls** on providers that end them only with the completed response.
- **TUI**: the model picker stays responsive with large catalogs such as OpenRouter's, the goal dialog scrolls when the goal is long, type-to-filter works in Message Actions, removing `theme` from config returns to the default theme, quick successive settings changes no longer overwrite each other, and the session list keeps its selected row after a deletion.
- **Plugins**: promise-based plugin API calls honor `signal`, and a plugin can give an agent `instructions` that apply only while that agent is selected without busting the prompt cache. A renderer passed to `registerCodeBlockRenderer` now receives an OpenTUI block (`block.text`) instead of a Markdown token, so `codeBlockStyle` and `escaped` are gone.
- **Smaller fixes**: a revoked ChatGPT sign-in asks you to connect again instead of failing every prompt with a 400, stored blobs are deleted a week after they are written, config reloads only when a file that feeds it changes, `opencode <name>` prints help instead of a stack trace, a FIFO passed to `opencode run` is rejected immediately, branches whose names end in `/HEAD` appear in the branch list, and the background service starts on a slow disk with a large write-ahead log.

Desktop-only changes in these releases (the built-in browser pane and its extension profile, differential updates, the file-tree sidebar position, Inbox pins, the Windows taskbar status, desktop keyboard shortcuts and the unread `/btw` dot) do not apply to this Termux build.

## What changed in this Android build

- **OpenTUI 0.9.9** replaces 0.8.4, built here for bionic against **Zig 0.17.1** with the same `--libc` schema and the `limits.h` shadow, and one stripped renderer asset still ships instead of the four Bun emits.
- **Four guard patches are gone**: OpenTUI 0.9.x clamps the buffer virtual-line, draw and renderer clip paths itself, so those patches are dropped instead of kept in place.
- **OpenTUI 0.9.9 adds a libc++ bundling step for its static archive**; on Android that step and the archive are skipped, and only the bionic shared renderer is built with the locked `--libc` file.

## Install

```sh
pkg install bun ripgrep libc++
curl -fsSL https://raw.githubusercontent.com/Spectra010s/opencode-termux/native-android/install.sh | sh
```

Or through the signed APT source, so `pkg install opencode` picks up new versions:

```sh
curl -fsSL https://raw.githubusercontent.com/Spectra010s/opencode-termux/native-android/setup-apt.sh | sh
pkg install opencode
```
