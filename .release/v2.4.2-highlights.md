### Highlights

- **New TUI look**: the new design is on by default and the theme called `opencode` is the new one. Pick `opencode-classic` in **Theme** to get the old colours back.
- **Automations**: you can now have the agent run a prompt, a script or a shell command on a timer, on a cron schedule, or when an MCP server sends an event. `/automation` manages them.
- **Video generation**: you can now generate videos with a provider that has a video model. They render in the background, survive a server restart and land in your workspace.
- **Images and videos cost less**: both tools now run inside Code Mode, so they no longer add around 700 tokens to every request.
- **Plugins update themselves**: pin a plugin to `@latest`, a version range or a Git branch and it is checked at startup and every 24 hours; a newer match loads without a restart.
- **GPT-6.2 System Prompt**: GPT-6.2 Sol and Astra, and the `gpt-latest` aliases, now use a system prompt written for GPT-6.2.
- **Esc Takes Back Your Last Message**: with an empty composer, Esc before the model has written anything puts your message back in the composer, images included.
- **GitHub Copilot reads `COPILOT_GITHUB_TOKEN`**: `GITHUB_TOKEN` is ignored now, so Actions and git tooling can no longer send the wrong account.
