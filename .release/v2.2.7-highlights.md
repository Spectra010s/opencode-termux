### Highlights

- **Copilot Auto**: pick **Auto** in the model picker and Copilot's router chooses the model for each session at the Auto discount.
- **A package you can download on mobile data**: the release is a 33.1 MB bundle that runs on Termux's `bun` instead of an 86 MB compiled binary.
- **MCP logins stay signed in**: servers that rotate refresh tokens no longer sign you out when several clients refresh at once.
- **`read` got smarter**: negative offsets read from the end of a file, and a missing file suggests close names.
- **Shell results say how they ended**: output ends with `Exit code: N`, and timeouts suggest a larger one.
